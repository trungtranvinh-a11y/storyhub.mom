STORYHUB TECHNICAL HANDOFF
Last updated: 2026-04-23

==================================================
1. CURRENT PRODUCT DIRECTION
==================================================

Project name:
- StoryHub

Actual product direction:
- Text Story Tracking & Analysis Workspace

This is NOT an AI writing workspace anymore.

Current product goal:
- import story text files
- parse them into structured data
- review parsed chapters
- review character candidates
- review event drafts
- track plot threads and timeline
- use a desktop-style workspace UI
- run both as web and as desktop app

Out of product scope right now:
- AI continue writing
- AI rewrite
- AI provider workflows
- collaboration
- relationship graph
- OCR pipeline

5. IMPORT PIPELINE
==================================================

- src/services/import-service.ts

Pipeline:
1. create ImportJob
2. normalize source text
3. create SourceDocument
4. split chapters
5. create Chapter rows
6. extract character candidates
7. create/update Character rows
8. link ChapterCharacter rows
9. draft Event rows
10. complete ImportJob

Important parser services:
- src/services/text-normalizer-service.ts
- src/services/chapter-split-service.ts
- src/services/character-candidate-service.ts
- src/services/event-draft-service.ts

Current parser quality:
- chapter split is decent
- event draft extraction is decent for MVP

Important packaging notes:
- desktop-bundle is generated
- dist-desktop is generated
- lint ignores these generated folders
- packaging currently works for win-unpacked
